# Juliana 的离线财务总账

一个无需账号、无需服务器的中文多币种财务账本。支持收入、支出、账户转账、信用卡还款、资产与负债、净资产、月度预算，以及 AUD/HKD 统一折算。

月度收支与预算集中在同一页。衣、食、住、行等分类每新增或修改一笔支出，都会立即显示该分类已用金额、剩余预算或超支金额，同时更新整月预算状态。

新版统一采用两位小数金额：预算、账户余额、账单应还、流水与手动折算都可精确到 `0.01`。分类预算区可以整块收起，折叠状态会保留；预算填写 `0.00` 表示该分类不设置额度。

网站图标已更换为蓝绿钱包图标，并提供浏览器标签页、iPhone/iPad 主屏幕与 PWA 所需尺寸。

## 使用方式

直接双击 `index.html` 即可在浏览器中打开。所有数据只保存在当前浏览器。

## 发布到 GitHub Pages

1. 将 ZIP 解压后的全部文件上传到 GitHub 仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/ (root)`，保存。

## 记账逻辑

- 收入增加资产账户余额。
- 现金或银行卡支出减少资产余额。
- 信用卡消费增加负债余额。
- 账户转账不计入收入或支出。
- 信用卡还款同时减少现金和负债，不重复计为消费。
- 净资产 = 折算后的资产合计 − 折算后的负债合计。

## 多币种换算

- 月报统一显示货币可选 AUD 或 HKD。
- 每笔流水可手动填写 AUD/HKD 实际折算值，手动值优先。
- 未填写手动值时使用“汇率与数据”中的默认换算率。
- 缺少换算率的金额不会被偷偷估算，而会标记为“待补换算”。

## 数据安全

- JSON 备份可完整恢复账户、负债、汇率、流水和预算。
- CSV 适合在 Excel、Numbers 或 Notion 中查看流水。
- 清理浏览器网站数据、更换浏览器或更换设备前，请先导出 JSON 备份。
